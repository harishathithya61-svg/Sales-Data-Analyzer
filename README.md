
# 🛍️ Sales Data Analyzer

### Python-Based Retail Sales Dashboard

## 📌 About the Project

Sales Data Analyzer is a Python-based web application that helps users analyze retail sales data through an interactive dashboard.

Users can upload their sales CSV files and generate a dashboard to understand their business performance.

## ✨ Features

- Upload retail sales CSV files
- Analyze sales data
- Generate sales dashboard
- Display data visualizations
- Download sample sales dataset
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- Matplotlib
- HTML
- CSS

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/harishathithya61-svg/Sales-Data-Analyzer.git
```

**2. Open the project folder**

```bash
cd Sales-Data-Analyzer
```

**3. Install required packages**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python app.py
```

**5. Open your browser**

```text
http://127.0.0.1:5000
```

## 📊 How to Use

1. Open the web application.
2. Upload your retail sales CSV file.
3. Click Generate Dashboard.
4. View the sales analysis and visualizations.
5. Download the sample CSV if required.

## 🎯 Project Objective

To simplify retail sales analysis using Python and data visualization techniques.
